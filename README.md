# Superstore Data Analysis

## Project Overview
This project analyzes the Sample Superstore dataset using Python, Pandas, and Matplotlib.

## Tools Used
- Python
- Jupyter Notebook
- Pandas
- Matplotlib

## Dataset
Sample - Superstore.csv

## Analysis Performed
- Loaded the dataset
- Displayed the first 5 rows
- Checked dataset information
- Generated summary statistics
- Checked for missing values
- Created Sales by Category bar chart
- Created Sales Distribution pie chart
- Created Profit by Category bar chart
- Created Sales by Region bar chart
- Created Sales by Customer Segment bar chart

## Conclusion
The analysis shows that the Technology category has the highest sales, followed by Furniture and Office Supplies. The project demonstrates basic data analysis and visualization using Python.
